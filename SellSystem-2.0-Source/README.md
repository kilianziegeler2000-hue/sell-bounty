# SellSystem 2.0

Paper 1.21.4 / Java 21 / Vault

## /sell
Öffnet ein großes Sell-Inventar.
- Lege Items in die oberen 45 Slots.
- Unten rechts ist der grüne Bestätigen-Button.
- Unten links ist Abbrechen.
- Nicht verkaufbare Items werden zurückgegeben.

## /sellmulti
Öffnet zuerst eine Kategorien-Leiste ähnlich dem Screenshot.
Klickst du eine Kategorie an, öffnet sich eine Mengen-Auswahl 1-20.
Ein Klick auf eine Zahl verkauft genau so viele passende Items aus deinem Inventar.

## Bearbeiten
Alle Preise und Kategorien stehen in `config.yml`.
